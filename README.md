# 一座岛的30天 · 复苏远征

纯 HTML/CSS/JavaScript 制作的单人生态策略卡牌游戏。标准局为 **30天**，入口 [index.html](index.html) 位于仓库根目录，无需构建即可运行。完整规则见 [游戏设计文档](GAME_DESIGN_DOCUMENT.md)。

## 一局怎么玩

- 初始 40 生命、3 种子、4 水分、14 张基础牌。每天恢复 3 行动力，最多保留上一天的 1 点，手牌补至 5 张。
- 看今晚的公开危机：伤害 = 冲击 − 对应生境等级×2 − 护盾，最低为 0。生态压力达到 10 时，额外受到 4 伤害。
- 首次开始或继续远征时会显示聚焦式新手引导，逐一解释资源、危机与操作；点击任意位置继续，右下角可跳过，之后可从「规则」重看。
- 手牌以浅扇形排列，抽牌时依次滑入；每日换牌先退场再发新牌。将牌向上拖动至少 72 像素后松手使用；键盘聚焦牌后按 Enter 或空格也可出牌。物种和设施牌会弹出选择面板。
- 水 → 草 → 林 → 水依序出牌，每次接对额外获得 3 护盾和 1 研究点；通用牌不断链。
- 第 30 天结束时，生命大于 0，且三项生态课题均已提交，即获胜。课题条件可以随时点击「查看 / 完成生态课题」了解。

## 核心系统

- **三种生境**独立成长到 3 级，建设不需要分区。草灌花 2 种子；湿地和森林还需要 2 水分。资源不足时建设牌会先补资源。每级草灌每天产种子，湿地每天维持水分，森林每天产护盾。
- **水分与生态压力**：水分上限 8，可建蓄水池提高至 10。水分溢出、失衡兔群和入侵季等会增加压力。压力达到 4 会降低种子收入；达到 7 次日少抽一张；达到 10 当晚反噬。
- **物种食物网**：满足生境条件后使用「物种迁入」引入蜜蜂、青蛙、兔群、狐狸、猫头鹰、水鸟。蜜蜂与猫头鹰是两项课题的必要条件，兔群与狐狸有捕食平衡关系。
- **永久设施**：最多保留 3 座，可替换。包括种子银行、气象站、巡护营地、生态实验室和蓄水池。
- **连续天气**：第 6～8 天干旱、第 13～15 天暴雨、第 18～20 天迁徙季、第 23～25 天入侵季。气象站可显示未来 5 天危机。预警标记最多保留 4 个，每个可使今晚冲击降低 3。
- **生态课题**：湿地循环、传粉网络、森林守护各需满足对应条件并支付 5 研究点。研究不再只是攒到一个固定数字。
- **牌组运营**：每 5 天进营地，在获得新卡、强化旧卡、移除一张卡或回复 10 生命中选一项。每天最多换牌两次，第一次免费、第二次消耗 1 行动力；标记保留的牌不参与换牌。巡护仍花 1 行动力换临时护盾。
- **功能牌**：接力行动零费获得 1 行动力；水力调度以 2 水分换 1 行动力和预警，水不足时变为护盾；重新勘察换掉其余手牌并尽量抽回等量新牌；定向检索可指定换掉一张牌、抽取两张，或保留手牌换取预警。首次营地固定出现接力行动候选。已打出或换出的牌当天不会立刻抽回。

每次行动自动保存至当前浏览器。v4 存档与旧版隔离，旧版数据不会被覆盖，但不能在新版继续。刷新后点击「继续远征」恢复。

## 文件与验证

- [js/data.js](js/data.js)：卡牌、物种、设施、课题及天气数据。
- [js/ecosystem.js](js/ecosystem.js)：规则引擎与可复现随机数。
- [js/ui.js](js/ui.js)、[js/main.js](js/main.js)：界面、拖牌交互、存档与选择流程。
- [style.css](style.css)：响应式样式。

需要 Node.js，无第三方测试依赖：

```sh
node tests/simulate.js
node tests/tutorial.js
node tests/hand-layout.js
node tests/drag.js
node tests/game-flow.js
node tests/balance.js
```

平衡回归在 200 个固定种子中，透明规划策略获胜 195 局，随机出牌获胜 0 局，完全不行动获胜 0 局。自动策略仅用于回归检测，并不等同真人胜率。
