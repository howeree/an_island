# 《一座岛的100天》

一个不依赖网络或第三方库的原生 H5 生态模拟小游戏。直接打开 `index.html` 即可游玩。

## 文件结构

```text
index.html             页面骨架
style.css              响应式界面、岛屿插画与动画
js/data.js             15 种物种、20 张行动卡、12 个随机事件
js/ecosystem.js        数值模拟、食物链与多样性计算
js/ui.js               岛屿、图鉴、生态网络、弹窗和结算界面
js/main.js             游戏流程和交互控制
js/audio.js            可选的 Web Audio 点击音效
```

## 运行

双击 `index.html`，或将它拖进任意现代浏览器。游戏不需要安装依赖、启动服务器或联网。

## 发布到 GitHub Pages

此项目已是可直接部署的静态站点：仓库根目录中的 `index.html` 就是入口。将整个项目推送到 GitHub 仓库后，在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录部署；GitHub 会提供一个可公开访问的 HTTPS 链接。

## 美术替换

当前版本的景观和物种全部由 CSS 与 emoji 绘制，故在 `assets` 文件夹为空时仍能运行。

若要替换成 AI 生成的透明 PNG，请保持统一的卡通俯视视角和色彩。将图片放入例如 `assets/species/fox.png`，然后在 `js/ui.js` 的 `lifeTokens` 函数中，把 `item.icon` 改为 `<img src="assets/species/${id}.png" alt="${item.name}">`；并为 `.scene-token img` 设置合适的 `width` 与 `height`。行动卡和图鉴中的物种图标也可按同样方式替换。建议保留 emoji 作为图片加载失败时的后备显示。

## 核心规则

- 每天从三张行动卡中选择一张，连续推进 100 天。
- 水、植被、森林、湿地和污染会影响 15 个物种的种群变化。
- 多样性由物种丰富度、三类栖息地、食物链、稳定性和均衡度共同计算；单独堆高一个物种不能获胜。
- 随机事件会说明原因、后果与影响；完整而均衡的生态系统更有韧性。
- 第 20、40、60、80 天会结算阶段目标。四个节点全部达成，才会依次解除生物多样性、稳定性、栖息地和食物链的 100 分上限。
- 部分高阶行动有生态前提；条件不足仅发挥 35% 效果。连续三次投入同一生态类别也会产生边际收益下降，因此需要观察右侧目标并安排恢复顺序。
