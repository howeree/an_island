# 《一座岛的100天》

一个不依赖网络或第三方库的原生 H5 生态模拟小游戏。直接打开 `index.html` 即可游玩。

## 文件结构

```text
index.html             页面骨架
style.css              连续岛屿景观、卡牌与拖动动画
js/data.js             15 种物种、35 张卡牌、8 类可预警危机
js/ecosystem.js        工程容量、生态结构与危机判定
js/ui.js               岛屿棋盘、牌组奖励、图鉴和结算界面
js/main.js             抽牌、能量、上拖出牌与 100 天流程
js/audio.js            可选的 Web Audio 点击音效
tests/simulate.js      无浏览器规则模拟测试
```

## 运行

双击 `index.html`，或将它拖进任意现代浏览器。游戏不需要安装依赖、启动服务器或联网。

## 发布到 GitHub Pages

此项目已是可直接部署的静态站点：仓库根目录中的 `index.html` 就是入口。将整个项目推送到 GitHub 仓库后，在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录部署；GitHub 会提供一个可公开访问的 HTTPS 链接。

## 美术替换

当前版本的岛屿、卡牌和物种全部由 CSS 与 emoji 绘制，故在 `assets` 文件夹为空时仍能运行。

若要替换成 AI 生成的透明 PNG，请保持统一的卡通俯视视角和色彩。建议在 `js/data.js` 中为物种或卡牌补充图片路径，并在 `js/ui.js` 的卡牌、岛屿和图鉴渲染处使用；保留 emoji 作为加载失败时的后备显示。

## 核心规则

- 时间逐日推进，一次“结束今天”只前进1天，共经营100天。
- 卡牌向上拖动并松手后立即生效；系统会自动选择最合适的生态位置，工程通常在一到两天后完工。
- 新手引导只显示当前一步，并用黄色边框标出推荐牌；行动力耗尽后会直接提示结束今天。
- 未来三次危机始终公开。湿地、廊道、捕食者、政策等结构会直接改变危机判定。
- 危机失败会把干裂土壤、有毒沉积、过度啃食、入侵藤蔓或游客惊扰塞入牌库；它们会占据抽牌并持续施压，直到被治理。
- Combo 来自真实空间结构，例如“溪流旁的水草湿地”与“兔群 + 狐狸 + 廊道”，而不是连续打出两个标签相同的牌。
- 每10天从三张牌中选一张加入牌组，也可跳过以保持牌组精简；第20、40、60、80天目标达成时可升级已有卡牌。
- 顶部指标只显示定性状态。精确分数仍用于内部结算，但无法再通过追着最低数字出牌获得四个 100。
