# 一座岛的100天 · 复苏远征

基于现有 H5 框架重构的生态策略卡牌游戏。标准局为 **30天、三阶段**，每天只推进一天。纯 HTML/CSS/JavaScript，无依赖，无构建步骤，入口 index.html 位于仓库根目录，可直接打开或通过 GitHub Pages 发布。

完整的玩法目标、系统规则、卡牌表、数值曲线与后续规划见 [游戏设计文档](GAME_DESIGN_DOCUMENT.md)。

## 一局怎么玩

- 初始40生命、3种子、10张基础牌，每天3行动力，抽至5张手牌（上限7张）。
- 每晚受到公开的生态冲击：实际伤害 = max(0, 冲击 − 对应生境等级×2 − 护盾)。
- 第10、20、30天分别遭遇水系20、草系32、林系46冲击。前三天是2/3/4冲击的学习缓冲，后续逐阶段增强。
- **胜利条件**：第30天存活，至少两种生境达到2级，累计至少24研究。生命归零立即失败；只存活但目标未完成，显示缺少的目标。
- 水→草→林→水，按顺序接牌，每次额外+3护盾、+1研究。可从任意一系开始；通用牌不断链，隔天重置。
- 每张卡显示当前真实结算预览，包含连携及生境增益。卡牌保持竖版外形，向上拖动72px后松手使用，也可聚焦后按Enter或空格。
- 不需要选分区或点击目标，建设绝不会覆盖已有生境。

## 永久建设与临时防御

三条生境各自从0级成长到3级。建设卡花2种子升1级，并获得2研究；种子不够时改为收集3种子，满级后改为8护盾和2研究。建设卡不会因为没有土地而失效。

| 生境 | 持续收益 | 2级生态网络 |
| --- | --- | --- |
| 湿地 | 每级抵消水系冲击2点 | 平安过夜回复1生命 |
| 草地与灌丛 | 每天获得等同等级的种子；每级抵消草系冲击2点 | 每天首次连携额外+2研究 |
| 森林 | 每天获得等同等级的护盾；每级抵消林系冲击2点 | 最多保留4点剩余护盾到明天 |

护盾在当晚使用，剩余通常丢弃。种子上限12。每晚最多额外保留1行动力；可以指定保留1张手牌，它占明天5张起手牌的一个位置。

## 调整牌组

- 每天一次换牌，花1行动力；标记保留的牌不参与换牌。可抽卡不足时会重新洗入旧手牌补足。
- 常备巡护：随时花1行动力获得3护盾，不需要抽到卡。
- 每5天进入营地：添加一张新卡 / 强化一种已有卡 / 移除一张卡 / 回复10生命，四选一。
- 同名卡全部共享升级；牌组至少6张；对应生境未到2级时，最后一张建设卡不可删除。
- 已打出的卡暂存在“今日已用”堆，到明天才进入弃牌堆，阻止零费过牌无限循环。
- 18种卡支持水系防御、林系防御与留盾、草系研究与连携等组合。

## 存档

每次行动自动保存至当前浏览器 localStorage。刷新后点击“继续”恢复手牌、危机序列和随机状态；浏览器不允许存储时仍可游玩。远征结束后可以查看牌组和每晚记录。存档按版本隔离，旧版土地制存档不能迁入。

## 文件

- index.html：根目录入口、资源与行动布局。
- style.css：响应式岛屿场景、清晰竖版卡牌、拖动与出牌动画。
- js/data.js：卡牌、路线、危机配置。
- js/ecosystem.js：纯规则引擎与可复现随机数。
- js/main.js：交互、存档、营地流程、指针拖动。
- js/ui.js：实时预览、牌组、营地与结算。
- js/audio.js：可选音效。

## 验证

需要 Node.js，无第三方测试依赖：

```sh
node tests/simulate.js
node tests/drag.js
node tests/game-flow.js
node tests/balance.js
```

规则测试覆盖连携、资源不足与满级建设、互不覆盖、留牌、换牌、防无限抽牌、营地暂停、关键牌保护、存档复现和明确胜负。拖动测试覆盖非中心抓取坐标、短拖、取消、释放与元素还原。流程测试实际出牌走完30天并获胜。

平衡测试比较200个固定种子的简单规划策略、随机出牌和完全不行动。当前规划策略200/200通关，随机出牌51/200，不行动0/200。这是自动策略对照，不等同于真人胜率；用于防止重新退化成“乱点也必胜”或“合理规划也无法通关”。
